# The Caffeinate

[The Caffeinate](https://thecaffeinate.com) is a free, privacy-first PDF editor for the web and desktop.

The web editor runs MuPDF.js locally in the browser. Selected documents, extracted text, edits, and exports are not uploaded to The Caffeinate. Current tools include continuous page preview, text search and replacement, highlighting, text placement, page organization, merging, splitting, text extraction, and PDF export.

## Run the website

```bash
cd frontend
npm install
npm run dev
```
